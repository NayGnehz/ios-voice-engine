# Android TTS 对接

本项目是系统 `TextToSpeechService`，不提供 HTTP 地址，无需在线中转。

- 通过显式包名选择音色，等待 `TextToSpeech.OnInitListener` 成功；`onInit` 不等于已有音频。服务仍等待音色就绪。
- 以 `setSpeechRate(float)` 设置倍速，后续新请求使用新值。已经提交或缓存的音频不会因参数修改而重新合成。需要立即生效时取消旧请求，再从稳定的内容位置提交新文本。
- 引擎通过 `SynthesisCallback.rangeStart(frame, start, end)` 发布位置。时间来自原生 PCM 帧；文本位置为相对于本次请求的 UTF-16 `[start,end)`。
- 回调并不保证一定是逐字或词语，也可能包含标点。显示高亮和维护暂停恢复位置应分开。不要让纯标点范围覆盖最近内容词的恢复锚点；还应测试词前带标点的范围。
- 阅读器需要保留“提交子串在原文中的基准偏移”，映射为原文位置，并核对请求标识，丢弃取消后的迟到回调。
- 取消不应依赖必然收到 `onDone`。检查 `onStop`、错误和自己的请求代次。
- 合成是串行同步原生调用。引擎停止会同步进入 `ve_ttsStop`，没有包装层超时保证。不要持有播放状态锁或阻塞 UI 等待停止、关闭和重分句；避免与正在等待音频消费的合成回调形成互等。
- 原生词标记是否由特定音色实际产生、时间是否吻合，以及新系统上的停止延迟均须实机验证。

当前服务不启用逐字拼读模式，也不删除原文标点。单独标点输入如何发音，不能仅由静态代码确认。
